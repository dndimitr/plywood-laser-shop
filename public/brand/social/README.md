# Studio Breza — Facebook assets

## Cover (мобилно безопасна версия)

Качете **`studio-breza-facebook-cover-1640x624.jpg`** (retina) или `820x312.jpg`.

Мобилният Facebook покрива **долен ляв ъгъл** с профилната снимка и **горната лента** с UI. Тази корица:

- няма голямо „B“ вляво (вече е в профилната)
- брандът е в центъра (safe zone)
- продуктите са вдясно
- долу вляво е изчистено за аватар
